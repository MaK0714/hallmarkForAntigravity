# Finish review

Open the actual desktop and mobile screenshots. If a view is blank, unstyled, missing or shows the wrong state, identify it and request a recapture before judging that view.

Read the requested outcome and identify the visitor's task from the screens. Assess hierarchy, brand fit, specificity, legibility, spacing, asset quality and whether the primary action is visible and understandable. For an app, assess density, the primary workflow and relevant states. Use the source only to locate or explain a finding. Distinguish interactions you tested from those you inferred.

For an existing site, compare the same states against the baseline and name anything the original did better. Judge a polish against its specific requested improvement and a redesign against its brief. Say which version to keep, or which changes to undo. A tie keeps the original. Report the few findings that would change the outcome, with their viewport, location and visual evidence.
