# First-screen review

Compare the actual desktop and mobile renders against the brief. From each, identify the subject the visitor sees first, the primary action and the asset or idea that anchors the page. Flag visual evidence that makes the task harder, such as ambiguous hierarchy, unreadable type or a crop that hides the subject. If comparing concepts, choose the one that best serves the material and visitor, or name what would make either viable. When given an existing baseline, name what it does better. Request a recapture for missing or unusable views.
