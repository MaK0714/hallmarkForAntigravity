# Repair Cafe

**Borrow the move.** Put location finding ahead of a mission statement.

## Task and emotional interpretation

Visitor task: find a local service. Emotional register: practical welcome. This is an interpretation of the sampled presentation, not a claim about the designers' private intent.

## Observed composition and type

The Visit page exposes a location map and a place-search area. Dark blue framing and orange accents connect the navigation to map markers. A large consent dialog blocks the initial view.

Bold sans headings and a blue/orange system make navigation and locations distinct; exact font identity is not established here.

## Transfer and placement

Use for local sessions, branches and community services. Offer a searchable list alongside the map, especially on phones.

## When it fails

Fails when a map is the only usable route or a consent overlay hides the locator. Map markers alone do not communicate dates, access or availability.

## Motion adaptation

Move the map only after user input and keep the selected location explicit in the list. These are adaptation recommendations. Animation timing, reduced-motion handling and downstream transactions were not validated in this sample.

## Evidence boundaries

Sampled 19 November 2026 at 1440x900 and 375x812. This is a bounded page sample, not an accessibility certification or a claim that the entire site is exemplary. Initial overlays are retained in the evidence; some dismiss controls were exercised in a separate capture. Computed font stacks describe declarations, not proof of downloaded font identity.
