# Design reference library

Choose by **visitor task, emotional stakes and material**. Add one case with comparable constraints or a deliberate opposite when it might change a decision. Read up to two full cases at a time. Each opens with a transferable move. Use this index alone for quick inspiration. The URLs document the evidence; the local notes are enough for routine or headless use. In a headless first pass, draft first unless a case resolves a decision that would otherwise block the draft.

Translate the move into the project's own content and style. In the handoff, identify the case, one visible decision it changed and the component where a reviewer can inspect it. Ground each action in the actual workflow. Treat staffing, queue rules and availability as facts that require evidence from the project. A free walk-in event calls for finding a session, and an empty search can offer clearing filters or browsing real categories. If several directions fit, consider the clearest, the most expressive and one plausible surprise. Choose according to the visitor's task. Humor can come from the subject, a tiny interaction or the copy. Keep critical actions, availability and error recovery easy to understand. Use motion to explain change, demonstrate an idea or set the rhythm. Design the still state as well.

Discovery sources include [Siteinspire](https://www.siteinspire.com/websites/selected) and [Landbook](https://land-book.com/sections). The cases use live sites and primary sources for details. Observations reflect the sampled pages on 16 November 2026. Interpretations are labelled and interaction gaps are recorded.
