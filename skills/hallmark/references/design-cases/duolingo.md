# Duolingo

**Borrow the move.** Let a mascot invite action while the action label stays literal.

## Task and emotional interpretation

Visitor task: start learning. Emotional register: playful encouragement. This is an interpretation of the sampled presentation, not a claim about the designers' private intent.

## Observed composition and type

A green owl in a phone illustration sits beside a short learning promise. Get started is filled green; returning-account access is secondary. The phone stack keeps both routes distinct.

Duolingo Sans; rounded letterforms, green and white reinforce a friendly character.

## Transfer and placement

Use for voluntary learning and low-stakes onboarding. Put returning-user access beside the first-step route.

## When it fails

Fails when mascot performance delays progress, childish styling conflicts with the audience, or praise replaces useful feedback.

## Motion adaptation

Use expressive reactions after a real answer. Still frames and reduced-motion equivalents must preserve the feedback. These are adaptation recommendations. Animation timing, reduced-motion handling and downstream transactions were not validated in this sample.

Sampled 19 November 2026 at 1440x900 and 375x812. This is a bounded page sample, not an accessibility certification or a claim that the entire site is exemplary.
